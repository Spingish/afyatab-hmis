# TibaMax HMIS - Roadmap

## Phase 1 (8-10 weeks) - Core single-facility system
- Patient registration
- Appointments
- Consultation
- Billing
- Pharmacy
- Laboratory
- Reports
- Basic Hospital Administration
- Deploy to own facility

## Phase 2 (6-8 weeks) - Multi-tenancy
- Multi-tenancy (facility_id scoping vs. separate installs - decide architecture here)
- Super Admin Portal (cross-facility)
- Subscription management
- Facility onboarding
- Tenant management

## Phase 3 (8-12 weeks) - Scale & maturity
- Advanced analytics
- Audit centre
- Security centre
- API marketplace
- Developer tools
- High availability
- Performance optimisation
